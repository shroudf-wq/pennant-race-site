# ペナントレース シミュレーター 紹介サイト

架空のプロ野球リーグで遊ぶブラウザゲーム「ペナントレース シミュレーター」の紹介ページです(1ページだけ)。

- 体験版: `play/index.html`(サイト用の体験版。1ファイル。本編だけの機能のプログラムは抜いてあり、本編のセーブは読み込めない)
- 最新版: v1.3.y(2026-10-24)

## 更新のしかた

体験版を新しい版にするときは、`play/index.html` を新しいサイト用の体験版に置き換えます(名前は `index.html` のまま)。サイト用の体験版は、プロジェクトの `claude/site/` の道具(`make_lite_site.py`)で本編のソースから作ります(いつもの体験版のファイルをそのまま置かないこと)。


`index.html` の次の2か所を直します。

- 版と日付: `最新版 v1.3.y / 2026.10.24`
- 本編を公開したら、`本編は近日公開予定` の `<span class="btn sub">` を、本編のリンク(`<a class="btn sub" href="...">`)に替える

登場する球団・選手はすべて架空です。
